# ScienceClaw Epilepsy Collective

[Open the interactive slides](https://scienceclaw-anya.github.io/epilepsy-collective-slides/)

This repository hosts the supplied ScienceClaw Epilepsy Collective presentation as a self-contained HTML file.

Use the on-screen arrow controls or the left/right arrow keys to move through the seven slides. The interactive 3D view requires a browser with WebGL support.

GitHub Pages publishes the repository root from the `main` branch. To update the presentation, replace `index.html` and commit to `main`.
